# 🛡️ Saurav Kumar | Application Security & Full-Stack Portfolio

Welcome to the source code of my professional portfolio! This project serves not just as a resume, but as a live demonstration of my skills in **Full-Stack Engineering** and **Application Security**.

🔗 **Live Site:** [astro-saurav.xyz](https://astro-saurav.xyz)

## ✨ Features
- **Security-First Architecture**: Built with strict CSP, HSTS, secure headers, and Trusted Types configurations.
- **Modern Tech Stack**: Next.js 15 (App Router), React, Tailwind CSS, and Shadcn UI.
- **Interactive UI**: Fluid animations powered by Framer Motion and an easter-egg terminal interface for contacts.
- **SEO Optimized**: Fully configured robots.txt, sitemap.xml, and dynamic metadata.
- **Performant**: Edge-deployed with Vercel for extremely low latency.

## 🛠️ Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Astro-Saurav/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🤝 Contributing & Pull Requests

This repository is structured to allow for easy cross-account contributions. 

**To open a Pull Request to your other account:**
1. Go to your primary repository on GitHub (the one you want to update).
2. Go to the **Pull Requests** tab and click **New pull request**.
3. Click **compare across forks**.
4. Set the **base repository** to your primary account's repo.
5. Set the **head repository** to `Astro-Saurav/Portfolio`.
6. Click **Create pull request** to merge all these new changes!
